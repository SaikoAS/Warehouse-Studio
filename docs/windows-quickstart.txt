Warehouse Studio for Windows
============================

Use Windows with Microsoft Edge and an approved Python 3.13 or newer with
standard-library sqlite3 already available. Extract the whole ZIP into a local
folder you can write to. Start from the extracted folder.

1. Double-click Start Warehouse Studio.cmd. The launcher opens in Edge.
2. In File Explorer, copy the absolute path to a writable local data folder
   outside the extracted application. Paste it into Project folder path and
   select Use folder. The optional Browse button uses Tk when available.
3. Create or open a project. The launcher closes when the project is ready.
   Warehouse Studio supports one active project and stores its data in a
   .warehouse.sqlite3 file in the selected data folder.
4. Open Import, Data preparation or Results from the project window. Each opens
   in its own Edge window. Select a module again to bring its window forward.
5. Choose a CSV in Import, check the encoding, delimiter, and preview, then
   select Import CSV. Add steps in Data preparation and use Apply to save the
   result. Select a result line number to see the original record.
6. Choose Close project to close the project and its modules and return to the
   launcher. If a module has unsaved changes, you can cancel the close.

Keep the start window open while using Warehouse Studio. Press Ctrl+C there to
stop the local service.

The scripts find python.exe through your user environment. If your approved
installation needs an explicit choice, set WAREHOUSE_STUDIO_PYTHON to the full
path of its python.exe in your environment before starting.

Optional Start menu shortcut
----------------------------

Double-click Create Warehouse Studio Shortcut.cmd to add Warehouse Studio to
your own Start menu. The shortcut starts this extracted copy. Run Remove
Warehouse Studio Shortcut.cmd from the same folder before moving or removing
it. This removes the shortcut and leaves the application and project files in
place. Windows must allow write access to your own Start menu Programs folder.
